# LI Personal Hub Backups

Персональный инструмент для резервного копирования данных хаба в Google Drive.

## Что делает приложение

Хаб хранит дела, расписание, отметки привычек, записи занятий и идеи своего владельца. Приложение регулярно сохраняет копию этой базы в его Google Drive. После загрузки оно скачивает копию обратно и проверяет её целостность.

Копии помогают восстановить данные при потере или повреждении сервера. Работа приложения управляется владельцем хаба.

## Зачем нужен доступ к Google Drive

Приложение запрашивает разрешение `drive.file`: работу с файлами, которые оно создаёт или к которым пользователь отдельно предоставляет доступ. Для резервирования оно использует собственные файлы в папке **LI-Personal-Hub-Backups**.

Подключение выполняется через экран согласия Google. Владелец может отозвать доступ в [настройках подключений Google-аккаунта](https://myaccount.google.com/connections).

## Работа с данными

Назначение доступа, хранение копий, удаление данных и сведения для связи описаны в [политике работы с данными](privacy.html).
